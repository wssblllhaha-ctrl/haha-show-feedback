# haha.show 反馈处

这里是 [haha.show](https://haha.show) 的问题反馈与建议收集处。

站点本身不接后端，所以没有评论区、也没有埋点。想说什么，请直接在这里开 issue。

## 怎么提

| 我想… | 点这个 |
| --- | --- |
| 报告一个坏掉的地方 | [新建 Bug 报告](https://github.com/wssblllhaha-ctrl/haha-show-feedback/issues/new?template=bug_report.yml) |
| 提功能或内容建议 | [新建建议](https://github.com/wssblllhaha-ctrl/haha-show-feedback/issues/new?template=suggestion.yml) |

不想填表的话，直接在 [Issues](https://github.com/wssblllhaha-ctrl/haha-show-feedback/issues/new) 里写一句话也行，能说清「在哪、什么设备、看到了什么」就够。

## 提之前

- 看看 [已有的 issue](../../issues?q=is%3Aissue) 里有没有人提过，避免重复。
- 已知问题（比如 iOS 深色模式下的自动配色）已经开好 issue 置顶，不用重复报，补充信息请跟帖。

## 关于回复

这是个人项目，回复不一定及时，但都会看。修好的会在对应 issue 里说明并关联变更。

## 隐私

请不要在 issue 里贴 API key、密码、私人文件路径、真实住址一类的东西。截图前记得打码。
